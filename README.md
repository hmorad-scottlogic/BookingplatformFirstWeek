# BookingPlatform

A multi-tenant platform for clubs and community organisations.

## Script commands
Run all tests with 'npm run' followed by the following:

test = run all tests
test:headed = run tests as headed
test:smoke = run all smoke tests
test:defect = run all defect tests
test:ui = run tests in UI mode
test:debug = run tests in debug mode
codegen = run codegen

## Defect testing method
Tests that are currently failing and need a fix in a future update have been tagged with the 'defect' tag

We have chosen these tests to pass currently and will have a description that describes what is failing.

These tests are to have their 'defect' tag removed as well as their .fail in their test after the feature has been fixed.
